## 🧠 About Me

I'm a software engineering student at **ICT University, Yaoundé** building real software for real African problems — agriculture, youth employment, university tooling, local commerce.

I move across the stack: React frontends, Flutter & React Native apps, Node and Java backends, JavaFX desktop, Docker deployments, and clean architectures wired up with CI/CD.

- 🎓 Studying **Java**, **Advanced Web Dev**, **Software Architecture**, **Android Dev**
- 🌍 Building for **🇨🇲 Cameroon & Africa first**
- 🤝 Open to **collaborations, internships, and freelance work**
- ⚡ Fun fact: I shipped a hybrid offline-first crop database for **52 Cameroonian crops** with on-demand AI enrichment
